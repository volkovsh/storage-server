# Лабораторная 5 — Удалённое файловое хранилище (REST API по HTTP)

Сервис реализует удалённое файловое хранилище. Путь в URL задаёт логическое расположение файла/каталога в хранилище.

Пример: `http://localhost:8000/path/to/file` соответствует файлу `file` по пути `/path/to` (расширение не требуется).

## Запуск

```bash
python3 storage_server.py --host 0.0.0.0 --port 8000 --root storage_data
```

## REST API

Базовый URL: `http://<IP_сервера>:8000/`.

- **PUT** `/path/to/file.txt` — загрузка/перезапись файла (`201/200`)
- **PUT** `/path/to/new.txt` + `X-Copy-From: /path/to/src.txt` — копирование (`201/200`, если исходник отсутствует — `404`)
- **GET** `/path/to/file.txt` — скачать файл (`200`)
- **GET** `/path/to/dir/` — список каталога (JSON, `200`)
- **HEAD** `/path/to/file.txt` — метаданные (`Content-Length`, `Last-Modified`)
- **DELETE** `/path/to/file_or_dir` — удалить (`204`, если отсутствует — `404`)

Тестировать удобно через Postman или curl (см. `ОТЧЁТ_лаб5.md`).

## Примечания

- Каталоги создаются автоматически при `PUT`.
- Для чтения больших файлов используется потоковая передача (без загрузки файла целиком в память).
- Защита от выхода за пределы корня хранилища: `..` не допускается.
